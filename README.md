# 🎲 Dice Duel Game

A simple and modern dice game built with **HTML, CSS, and JavaScript**.

Player and Computer roll the dice.  
Whoever rolls the higher number wins the round 🏆

---

## 🕹️ How to Play
1. Click **Roll Dice**
2. Player and Computer roll simultaneously
3. Higher dice wins the round
4. Scores update automatically
5. Click **Reset** to start over

---

## ✨ Features
- 🎲 Random dice rolls
- 🧮 Live score tracking
- 🎨 Modern UI with smooth transitions
- ❓ Dice placeholder before game starts
- 🔄 Reset functionality

---

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, CSS Variables)
- JavaScript (DOM Manipulation)
